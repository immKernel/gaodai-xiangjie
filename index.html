例 1.1 与例 1.2 的小白版讲解

每一步只做一件事，不跳步。绿色框是“用具体数字验算”，黄色框是“为什么会想到这样做”。

先弄懂一个词：“整除”是什么意思？

$A \mid B$ 读作“$A$ 整除 $B$”，意思是：$B$ 可以写成 $A$ 乘以某个多项式，即 $B = A\cdot Q$。

例如 $x^2 \mid x^3 + x^2$，因为 $x^3+x^2 = x^2\cdot(x+1)$，这里 $Q = x+1$。

所以要证明“$A$ 整除 $B$”，最直接的办法就是：把 $B$ 硬算成“$A\times$ 某个东西”的样子。下面两题都是这个思路。

例 1.1

题目（原书第 2 页）

设 $k, n$ 为正整数，令

$$f(x) = (x+1)^{k+n} + 2x(x+1)^{k+n-1} + \cdots + (2x)^k (x+1)^n .$$

证明：$x^{k+1} \mid (x-1)f(x) + (x+1)^{k+n+1}$。

一句话思路：把 $(x-1)f(x) + (x+1)^{k+n+1}$ 实实在在算出来，会发现它等于 $x^{k+1}\times$ 某个多项式。难点只在于 $f(x)$ 是一长串“$\cdots$”，需要一个公式把它收拢。

  1. 先拿小数字试一试，看看结论长什么样

    取最小的 $k=1,\ n=1$。此时 $f(x)$ 只有两项（$2x$ 的次数从 $0$ 到 $k=1$）：

    $$f(x) = (x+1)^2 + 2x(x+1) = (x+1)(x+1+2x) = (x+1)(3x+1) = 3x^2+4x+1.$$

    要检查的式子是：

    $$\begin{aligned} (x-1)f(x) &= (x-1)(3x^2+4x+1) = 3x^3 + x^2 - 3x - 1,\\ (x+1)^{3} &= x^3+3x^2+3x+1,\\ \text{两者相加} &= 4x^3 + 4x^2 = x^2\cdot 4(x+1). \end{aligned}$$
    验算结果

    结果确实是 $x^2 = x^{k+1}$ 乘一个多项式，结论成立。而且中间的 $x$ 项、常数项都恰好抵消了，说明背后有个“抵消公式”。下面找出它。

  2. 看清 $f(x)$ 每一项的规律

    把 $f(x)$ 的各项排成表格，只看两个括号各自的次数：

    第几项$(2x)$ 的次数$(x+1)$ 的次数两个次数之和
    第 0 项$0$$k+n$$k+n$
    第 1 项$1$$k+n-1$$k+n$
    第 2 项$2$$k+n-2$$k+n$
    $\vdots$$\vdots$$\vdots$$\vdots$
    第 $k$ 项（最后）$k$$n$（最小）$k+n$

    规律：$(2x)$ 的次数一个一个加 1，$(x+1)$ 的次数一个一个减 1，最少也有 $n$ 次。

  3. 把每项都有的 $(x+1)^n$ 提出来

    既然每一项至少含 $n$ 个 $(x+1)$，就像提公因数一样把 $(x+1)^n$ 提到外面：

    $$f(x) = (x+1)^n\Big[\,(x+1)^{k} + (2x)(x+1)^{k-1} + (2x)^2(x+1)^{k-2} + \cdots + (2x)^k\,\Big].$$

    检查一下：括号里第 $j$ 项是 $(2x)^j(x+1)^{k-j}$，乘上外面的 $(x+1)^n$ 正好变回原来的 $(2x)^j(x+1)^{k+n-j}$。

  4. 给两个括号起短名字，认出熟悉的公式

    令 $A = x+1,\ B = 2x$。方括号里就变成

    $$A^k + A^{k-1}B + A^{k-2}B^2 + \cdots + B^k .$$

    这个样子你其实见过。中学的公式：

    $$a^2-b^2 = (a-b)(a+b),\qquad a^3-b^3=(a-b)(a^2+ab+b^2).$$

    第二个公式右边的括号 $a^2+ab+b^2$，正是“$a$ 的次数递减、$b$ 的次数递增”。一般地有：

    $$\boxed{\,A^{k+1}-B^{k+1} = (A-B)\big(A^k + A^{k-1}B + \cdots + B^k\big)\,}$$
    为什么会想到这个公式？

    只要看到一串“一个字母次数往下降、另一个往上升”的和，就该想到它。它其实就是等比数列求和公式，相邻两项的比都是 $B/A$。

  5. 用图看懂这个公式为什么对（以 $k=2$ 为例）

    计算 $(A-B)(A^2+AB+B^2)$：先用 $A$ 去乘括号得到第一行，再用 $-B$ 去乘括号得到第二行。把同类项上下对齐：

  6. 把 $A = x+1,\ B = 2x$ 代回公式

    先算 $A - B$：

    $$A - B = (x+1) - 2x = 1 - x.$$

    于是公式变成

    $$(1-x)\Big[(x+1)^{k} + (2x)(x+1)^{k-1} + \cdots + (2x)^k\Big] = (x+1)^{k+1} - (2x)^{k+1}.$$

    左边的方括号正是第 2 步里 $f(x)$ 的方括号。

  7. 两边同乘 $(x+1)^n$，左边就凑出了 $f(x)$

    由第 2 步，$f(x) = (x+1)^n\times[\text{方括号}]$，所以左边乘 $(x+1)^n$ 后变成 $(1-x)f(x)$：

    $$\begin{aligned} (1-x)f(x) &= (x+1)^n\Big[(x+1)^{k+1} - (2x)^{k+1}\Big]\\ &= (x+1)^{k+n+1} - 2^{k+1}x^{k+1}(x+1)^n . \end{aligned}$$

    第二行用了两个小事实：$(x+1)^n(x+1)^{k+1} = (x+1)^{k+n+1}$（同底数幂相乘，指数相加）；$(2x)^{k+1} = 2^{k+1}x^{k+1}$。

  8. 调整成题目要的样子

    题目里是 $(x-1)f(x)$，我们手里是 $(1-x)f(x)$。二者只差一个负号：$x-1 = -(1-x)$。把上式两边都乘 $-1$：

    $$(x-1)f(x) = -(x+1)^{k+n+1} + 2^{k+1}x^{k+1}(x+1)^n .$$

    两边再同时加上 $(x+1)^{k+n+1}$，右边的 $-(x+1)^{k+n+1}$ 就被消掉：

    $$(x-1)f(x) + (x+1)^{k+n+1} = 2^{k+1}x^{k+1}(x+1)^n .$$

  9. 得出结论

    右边可以写成

    $$x^{k+1}\cdot\underbrace{2^{k+1}(x+1)^n}_{Q(x)} .$$

    $Q(x) = 2^{k+1}(x+1)^n$ 是一个多项式，所以按“整除”的定义，$x^{k+1} \mid (x-1)f(x) + (x+1)^{k+n+1}$。证毕。

    和第 0 步对一下

    $k=n=1$ 时，公式给出 $2^{2}x^{2}(x+1) = 4x^2(x+1)$，与第 0 步硬算的结果完全一样。

对照：原书的解析（很短，对比一下哪里被跳过了）

提出每项公有的因式 $(x+1)^n$，得到 $f(x)=(x+1)^n\sum_{j=0}^{k}(2x)^j(x+1)^{k-j}$。对任意 $A,B$，把 $A-B$ 乘到 $\sum_{j=0}^k A^{k-j}B^j$ 上，得到 $A^{k+1}-B^{k+1}$。取 $A=x+1,B=2x$，则 $A-B=1-x$。代入并移项，$(x-1)f(x)+(x+1)^{k+n+1}=2^{k+1}x^{k+1}(x+1)^n$。右端含因式 $x^{k+1}$，所证即得。

这题记住什么

  • 看到“一个次数降、一个次数升”的一串和，就用 $A^{k+1}-B^{k+1}=(A-B)(\cdots)$ 把它收拢。
  • 证明整除，就是把式子算成“除式 × 多项式”。
  • 拿 $k=n=1$ 这样的小数字先试，既能找方向，也能验算答案。

例 1.2

题目（原书第 2 页）

设 $m, n, p$ 是非负整数。证明：$x^2+x+1$ 整除 $x^{3m}+x^{3n+1}+x^{3p+2}$。

一句话思路：$x^2+x+1$ 和 $x^3$ 有一层特殊关系：在“除以 $x^2+x+1$ 看余数”的意义下，$x^3$ 就相当于 $1$。于是题目里那三个很高次的项，各自都能缩成 $1$、$x$、$x^2$，加起来正好是 $x^2+x+1$ 本身。

  1. 先拿小数字试一试

    取 $m=n=p=1$：

    $$x^{3}+x^{4}+x^{5} = x^3(1+x+x^2).$$
    验算结果

    确实是 $x^2+x+1$ 的倍数。但如果取 $m=0,\ n=1,\ p=2$，式子是 $1+x^4+x^8$，就看不出来了。所以需要一个通用方法。

  2. 关键事实：$x^3-1 = (x-1)(x^2+x+1)$

    把右边展开验证一下：

    $$(x-1)(x^2+x+1) = x^3 + x^2 + x - x^2 - x - 1 = x^3 - 1.$$

    这说明 $x^3 - 1$ 是 $x^2+x+1$ 的倍数。（这其实就是例 1.1 里那个公式取 $A=x,\ B=1,\ k=2$ 的情形。）

  3. 推广：$x^{3m}-1$ 也是 $x^2+x+1$ 的倍数

    把 $x^{3m}$ 看成 $(x^3)^m$，再用例 1.1 的公式（取 $A = x^3,\ B=1$）：

    $$x^{3m} - 1 = (x^3)^m - 1^m = (x^3 - 1)\big[(x^3)^{m-1} + (x^3)^{m-2} + \cdots + 1\big].$$

    它是 $x^3-1$ 的倍数，而 $x^3-1$ 又是 $x^2+x+1$ 的倍数，所以 $x^{3m}-1$ 是 $x^2+x+1$ 的倍数。

    如果 $m=0$，那么 $x^{0}-1 = 0$，而 $0 = (x^2+x+1)\cdot 0$，也算倍数。所以对所有非负整数 $m$ 都成立。同理 $x^{3n}-1$、$x^{3p}-1$ 也都是倍数。

  4. 把要证的式子“拆”成几个倍数相加

    记 $g(x) = x^{3m}+x^{3n+1}+x^{3p+2}$。这里用一个技巧：先减去 $1+x+x^2$，再加回来。

    $$\begin{aligned} g(x) &= \big(x^{3m} - 1\big) + \big(x^{3n+1} - x\big) + \big(x^{3p+2} - x^2\big) + \big(1 + x + x^2\big)\\[2pt] &= \underbrace{\big(x^{3m} - 1\big)}_{\text{倍数}} + x\underbrace{\big(x^{3n} - 1\big)}_{\text{倍数}} + x^2\underbrace{\big(x^{3p} - 1\big)}_{\text{倍数}} + \underbrace{\big(x^2 + x + 1\big)}_{\text{它本身}}. \end{aligned}$$

    第二行是把 $x^{3n+1}-x$ 提出一个 $x$，把 $x^{3p+2}-x^2$ 提出一个 $x^2$。

  5. 得出结论

    四个部分每一个都是 $x^2+x+1$ 的倍数（倍数乘以 $x$、$x^2$ 还是倍数）。几个倍数加起来还是倍数，所以

    $$x^2+x+1 \;\big|\; x^{3m}+x^{3n+1}+x^{3p+2}.\qquad\text{证毕。}$$

用图理解：“$x^3$ 相当于 $1$”像一个只有 3 格的钟

第 2、3 步说明，除以 $x^2+x+1$ 只看余数时，每遇到一个 $x^3$ 都可以换成 $1$。所以 $x$ 的指数只需要看除以 3 的余数：每乘一次 $x$，指针就往前走一格，走 3 格回到起点。

拿第 0 步里看不出来的 $1+x^4+x^8$ 试一下：指数 $0,4,8$ 除以 3 分别余 $0,1,2$，三格各一个，所以它也能被 $x^2+x+1$ 整除。

另一种看法：用根，在复平面上画出来

解方程 $x^2+x+1=0$，用求根公式得两个根：

$$\omega = \frac{-1+\sqrt{3}\,i}{2},\qquad \omega^2 = \frac{-1-\sqrt{3}\,i}{2}.$$

由第 1 步，$\omega^3 - 1 = (\omega-1)(\omega^2+\omega+1) = (\omega-1)\cdot 0 = 0$，所以 $\omega^3 = 1$。

代入 $\omega$：$g(\omega) = \omega^{3m} + \omega^{3n+1} + \omega^{3p+2} = 1 + \omega + \omega^2 = 0$。

代入 $\omega^2$：$(\omega^2)^{3m}=1$，$(\omega^2)^{3n+1} = \omega^{6n}\cdot\omega^2 = \omega^2$，$(\omega^2)^{3p+2} = \omega^{6p}\cdot\omega^{4} = \omega$，所以 $g(\omega^2) = 1+\omega^2+\omega = 0$。

$x^2+x+1$ 的两个根 $\omega, \omega^2$ 都是 $g(x)$ 的根，并且这两个根不相等，所以 $x^2+x+1 = (x-\omega)(x-\omega^2)$ 整除 $g(x)$。

说明

这个方法借用了复数。整除关系不会因为“在实数里算”还是“在复数里算”而改变（带余除法的商和余数是同一个），所以结论在实系数多项式里同样成立。考试中两种写法都可以，前一种（拆成倍数）完全不用复数，更稳妥。

对照：原书的解析

因 $x^3-1=(x-1)(x^2+x+1)$，模 $x^2+x+1$ 有 $x^3\equiv 1$。于是 $x^{3m}\equiv 1,\ x^{3n+1}=x(x^3)^n\equiv x,\ x^{3p+2}=x^2(x^3)^p\equiv x^2$。三式相加，得到被除式同余于 $1+x+x^2$，而它本身就是除式，故原式同余于零。

这题记住什么

  • 除式是 $x^2+x+1$ 时，先想到 $x^3-1=(x-1)(x^2+x+1)$，于是 $x^3$“相当于”$1$，指数只看除以 3 的余数。
  • 严格写法：减去 $1+x+x^2$ 再加回来，把式子拆成几个倍数之和。
  • 另一条路：找出除式的根，代入被除式看是不是 $0$。
