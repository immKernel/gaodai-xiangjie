例 1.4

题目（原书第 3 页）

用综合除法将 $2x^4+x^3+7x^2-8x+14$ 写成

$$a\,x(x-1)(x-2)(x-3) + b\,x(x-1)(x-2) + c\,x(x-1) + d\,x + e,$$

列出综合除法算式并求 $a,b,c,d,e$。

一句话思路：依次除以 $x,\ x-1,\ x-2,\ x-3$，每次把商拿去做下一次的被除式。四次的余数从下往上，就是 $e, d, c, b$，最后剩下的商就是 $a$。

  1. 先学会综合除法（除以 $x-c$ 的快速算法）

    以 $(2x^2+3x+10)\div(x-2)$ 为例。把系数 $2,3,10$ 排成一行，左边写 $c=2$：

    22310
    414
    2724

    规则只有三条：

    • 第一个系数 $2$ 直接落下来。
    • 落下来的数乘 $c$，写到下一列：$2\times 2 = 4$；这一列相加：$3+4 = 7$。
    • 重复：$7\times 2 = 14$，$10+14 = 24$。

    最后一个数 $24$ 是余数，前面的 $2, 7$ 是商的系数，即商 $=2x+7$。也就是 $2x^2+3x+10 = (x-2)(2x+7) + 24$。展开右边：$2x^2+7x-4x-14+24 = 2x^2+3x+10$，对。

  2. 为什么要“连续除”？看题目式子的结构

    题目要的式子，每一项都比后一项多乘一个因子，可以一层层提公因式，像套娃：

    $$\begin{aligned} &= x\Big[\,a(x-1)(x-2)(x-3) + b(x-1)(x-2) + c(x-1) + d\,\Big] + e\\ &= x\Big[(x-1)\big[\,a(x-2)(x-3) + b(x-2) + c\,\big] + d\Big] + e\\ &= x\Big[(x-1)\big[(x-2)\big(a(x-3) + b\big) + c\big] + d\Big] + e. \end{aligned}$$

    所以：原式除以 $x$ 的余数是 $e$；商再除以 $x-1$，余数是 $d$；商再除以 $x-2$，余数是 $c$；商再除以 $x-3$，余数是 $b$，商是 $a$。

  3. 四次综合除法

    系数是 $2,\ 1,\ 7,\ -8,\ 14$（注意 $-8x$ 的负号）。每一段用上一段的商（绿色左边的那些数）继续除：

    0217−814
    0000
    217−814 = e
    1217−8
    2310
    23102 = d
    22310
    414
    2724 = c
    327
    6
    2 = a13 = b

    逐段说明：

    • 除以 $x$（$c=0$）：乘 $0$ 全是 $0$，商 $2x^3+x^2+7x-8$，余数 $14$。
    • 除以 $x-1$：$1+2=3$，$7+3=10$，$-8+10=2$。商 $2x^2+3x+10$，余数 $2$。
    • 除以 $x-2$：就是第 0 步的例子，商 $2x+7$，余数 $24$。
    • 除以 $x-3$：$7+2\times3 = 13$。商 $2$，余数 $13$。

  4. 写出答案

    $$(a,b,c,d,e) = (2,\ 13,\ 24,\ 2,\ 14),$$ $$2x^4+x^3+7x^2-8x+14 = 2x(x-1)(x-2)(x-3) + 13x(x-1)(x-2) + 24x(x-1) + 2x + 14.$$
    代数字验算（不用展开）

    右边代入 $x=0,1,2,3$ 时很多项变成 $0$，非常好算。原式记作 $P(x)$：

    • $x=0$：右边 $= e = 14$；$P(0) = 14$。✓
    • $x=1$：右边 $= d+e = 16$；$P(1) = 2+1+7-8+14 = 16$。✓
    • $x=2$：右边 $= 2c + 2d + e = 48+4+14 = 66$；$P(2) = 32+8+28-16+14 = 66$。✓
    • $x=3$：右边 $= 6b+6c+3d+e = 78+144+6+14 = 242$；$P(3) = 162+27+63-24+14 = 242$。✓

    这个验算本身也是一种解法：依次代 $x=0,1,2,3$ 就能一个个解出 $e,d,c,b$。

这题记住什么

  • 综合除法三步：落下、乘 $c$、加到下一列。最后一个数是余数。
  • “套娃”形式的展开 = 连续做带余除法，余数从里到外依次是各个系数。
