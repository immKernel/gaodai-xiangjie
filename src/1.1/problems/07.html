例 1.7

题目（原书第 4 页）

设 $m, n, d$ 是正整数。证明：

$$\gcd(x^m-1,\ x^n-1) = x^d - 1 \iff \gcd(m,n) = d.$$

一句话思路：求两个整数的最大公因数，可以用“大数减小数”（更相减损术）：$\gcd(12,8)=\gcd(8,4)=\gcd(4,4)=4$。对 $x^m-1$ 和 $x^n-1$ 做同样的事，指数也跟着做“大减小”。所以两边每一步都对得上，最后得到 $\gcd(x^m-1,x^n-1) = x^{\gcd(m,n)}-1$。

  1. 先回忆：$\gcd$ 是什么

    $\gcd(F,G)$（最大公因式）是 $F,G$ 的公因式里次数最高、首项系数为 $1$ 的那个。一个基本性质：

    $$\gcd(F, G) = \gcd(G,\ F - Q\cdot G)\qquad(Q\text{ 是任意多项式}).$$

    理由：$F$ 和 $G$ 的公因式，一定整除 $F-QG$；反过来，$G$ 和 $F-QG$ 的公因式，一定整除 $F = (F-QG)+QG$。两组公因式完全相同，最大的那个当然也相同。

  2. 关键的一步“大减小”

    设 $m \gt n$。仿照例 1.6 的拆法：

    $$x^m - 1 = x^{m-n}(x^n - 1) + (x^{m-n} - 1).$$

    （展开右边：$x^m - x^{m-n} + x^{m-n} - 1$，对。）取 $Q = x^{m-n}$，由第 0 步：

    $$\gcd(x^m-1,\ x^n-1) = \gcd(x^n-1,\ x^{m-n}-1).$$

    左右两边的指数对 $(m,n)$ 变成了 $(n, m-n)$，这和整数的 $\gcd(m,n) = \gcd(n, m-n)$ 一模一样。

  3. 一直减下去，看一个具体例子

    $m=12,\ n=8$，左右两列同步进行：

    多项式那边整数那边
    $\gcd(x^{12}-1,\ x^{8}-1)$$\gcd(12, 8)$
    $=\gcd(x^{8}-1,\ x^{4}-1)$$=\gcd(8, 4)$
    $=\gcd(x^{4}-1,\ x^{4}-1)$$=\gcd(4, 4)$
    $= x^4 - 1$$= 4$

    每减一次，两个指数中较大的那个变小，所以总会停在两个指数相等的时候，此时整数那边等于 $\gcd(m,n)$，多项式那边是 $\gcd(x^{e}-1, x^{e}-1) = x^e - 1$，其中 $e = \gcd(m,n)$。（$x^e-1$ 首项系数是 $1$，正好符合 $\gcd$ 的要求。）

    结论：$\gcd(x^m-1,\ x^n-1) = x^{\gcd(m,n)} - 1$。

  4. 回到题目的“当且仅当”

    记 $e=\gcd(m,n)$，第 2 步已经说明 $\gcd(x^m-1,x^n-1) = x^e-1$。

    • 若 $\gcd(m,n)=d$，即 $e=d$，则最大公因式 $= x^d-1$。
    • 若最大公因式 $= x^d-1$，则 $x^d-1 = x^e-1$，比较次数得 $d = e = \gcd(m,n)$。

    证毕。

原书的做法（用 Bézout 等式，供对照）

记 $e=\gcd(m,n)$，$H=\gcd(x^m-1,x^n-1)$。由例 1.6，$x^e-1$ 同时整除两者，所以 $x^e-1\mid H$。取整数 $u\gt0, v\lt0$ 使 $um+vn=e$，令 $b=-vn\gt0$，则 $um = e+b$。由例 1.6，$H\mid x^{um}-1$ 且 $H\mid x^b-1$，相减得 $H\mid x^b(x^e-1)$。因为 $x^m-1$ 在 $x=0$ 处等于 $-1\ne0$，所以 $x\nmid H$，$H$ 与 $x^b$ 互素，于是 $H\mid x^e-1$。两者都首一且互相整除，故 $H = x^e-1$。

两种做法结论相同。上面的“大减小”做法就是把辗转相除法写成了减法，更容易看懂。

这题记住什么

  • $\gcd(x^m-1,\ x^n-1) = x^{\gcd(m,n)}-1$，这是常考结论，直接记住。
  • $\gcd(F,G)=\gcd(G, F-QG)$ 是辗转相除法的核心，整数和多项式都适用。
